# Data Contracts

The contracts below describe the core datasets generated by AstraFlow.

## customers.csv

Primary key: `customer_id`

Required fields:

- `customer_id`
- `signup_ts`
- `country`
- `city`
- `segment`
- `acquisition_channel`

## products.csv

Primary key: `sku`

Required fields:

- `sku`
- `category`
- `brand`
- `unit_price`
- `margin_percent`
- `supplier_region`

## orders.jsonl

Primary key: `order_id`

Required fields:

- `order_id`
- `customer_id`
- `order_ts`
- `channel`
- `status`
- `currency`
- `subtotal`
- `discount`
- `shipping_fee`
- `tax`
- `total_amount`
- `campaign_id`
- `device_type`

Rules:

- `customer_id` must exist in `customers.csv`.
- `total_amount` must be greater than or equal to zero.
- `status` must be one of `created`, `paid`, `shipped`, `delivered`, `cancelled`, `returned`.

## order_items.jsonl

Primary key: `order_item_id`

Required fields:

- `order_item_id`
- `order_id`
- `sku`
- `quantity`
- `unit_price`
- `gross_amount`
- `discount_amount`

Rules:

- `order_id` must exist in `orders.jsonl`.
- `sku` must exist in `products.csv`.
- `quantity` must be greater than zero.

## payments.jsonl

Primary key: `payment_id`

Required fields:

- `payment_id`
- `order_id`
- `payment_ts`
- `method`
- `status`
- `amount`
- `risk_score`

Rules:

- `order_id` must exist in `orders.jsonl`.
- `amount` must be greater than or equal to zero.
- `risk_score` must be between 0 and 1.

## shipments.jsonl

Primary key: `shipment_id`

Required fields:

- `shipment_id`
- `order_id`
- `warehouse_id`
- `shipped_ts`
- `delivered_ts`
- `carrier`
- `delivery_status`
- `promised_days`

Rules:

- `order_id` must exist in `orders.jsonl`.
- `promised_days` must be positive.

## clickstream_events.jsonl

Primary key: `event_id`

Required fields:

- `event_id`
- `event_ts`
- `customer_id`
- `session_id`
- `event_type`
- `sku`
- `campaign_id`
- `device_type`
- `page_latency_ms`

Rules:

- `customer_id` must exist in `customers.csv`.
- `page_latency_ms` must be between 0 and 10000.

## inventory_snapshots.jsonl

Primary key: `snapshot_id`

Required fields:

- `snapshot_id`
- `snapshot_ts`
- `sku`
- `warehouse_id`
- `on_hand`
- `reorder_point`
- `inbound_qty`

Rules:

- `sku` must exist in `products.csv`.
- Inventory quantities must not be negative.

## support_tickets.jsonl

Primary key: `ticket_id`

Required fields:

- `ticket_id`
- `order_id`
- `customer_id`
- `created_ts`
- `issue_type`
- `priority`
- `status`

Rules:

- `order_id` must exist in `orders.jsonl`.
- `customer_id` must exist in `customers.csv`.
